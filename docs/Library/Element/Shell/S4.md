# S4

Four Node Shell Element

The `S4` shell element uses [`Mindlin`](../Plate/Mindlin.md) plate element combined with [`GQ12`](../Membrane/Drilling/GQ12.md) element.

* Number of Nodes: 4
* Number of DoFs: 6 (Translation, Translation, Translation, Rotation, Rotation, Rotation)
* DoF Label: U1, U2, U3, UR1, UR2, UR3

![encoding](../PIC/Q4.svg)

## Background

S4 is the four-node flat shell assembled by [ShellBase](ShellBase.md) from two distinct two-dimensional elements.

The membrane action uses [GQ12](../Membrane/Drilling/GQ12.md), which supplies in-plane stiffness and the drilling rotation $$UR_3$$ through its generalized conforming interpolation.

The plate action uses the [Mindlin](../Plate/Mindlin.md) element, which retains transverse shear deformation and evaluates the shear term with one reduced-integration point to avoid shear locking.

Both actions share the same two-dimensional material matrix, and the plate curvature is integrated through the thickness at three fixed Gauss points with $$z=\xi t/2$$.

At a fibre the strain is $$\mathbf\varepsilon=\mathbf B_m\mathbf d_m+z\,\mathbf B_p\mathbf d_p$$, so the assembled local stiffness contains the membrane, bending and coupling blocks $$\mathbf K_{mm}$$, $$\mathbf K_{pp}$$ and $$\mathbf K_{mp}$$ described on [ShellBase](ShellBase.md).

The in-plane integration is 2-by-2 Gauss for both the membrane and the bending part, while the shear penalty is formed once at the element centre.

!!! info "deviation from theory"
    The transverse shear energy is replaced by a one-point penalty with a fixed coefficient of $$10/3\,G\,t\,\det\mathbf J$$ rather than by full integration of the shear strain.
    No separate transverse shear correction factor is computed.

!!! note "developer note"
    The through-thickness integration is fixed at three Gauss points.

The local triad and the corotational transformation of resistance and stiffness are inherited from `ShellBase`.

## Syntax

```text title="S4"
element S4 (1) (2...5) (6) [7] [8]
# (1) int, unique element tag
# (2...5) int, node i, j, k, l
# (6) int, material tag
# [7] double, thickness, default: 1.0
# [8] bool string, nonlinear geometry switch, default: false
```

## Remarks

1. If the nonlinear geometry is switched on, the transformation between the global and local reference frames will depend on the current displacement.
   The nonlinear transformation is similar to the corotational transformation, and the local response is still linear.
   Thus, it follows "large displacement, small deformation" assumption.

* The material must provide a nonzero shear modulus, since the Mindlin plate part builds its reduced-integration shear penalty from it.

!!! warning "implementation limitation"
    The GQ12 membrane has no drilling penalty, so the drilling rotation can be a zero-energy mode in an unconstrained patch.
    The material must report a nonzero shear modulus or initialization fails.

* Use a plane-stress two-dimensional material such as [`Elastic2D`](../../Material/Material2D/Elastic2D.md) to obtain the correct $$Et^3/[12(1-\nu^2)]$$ bending stiffness.
* The number of through-thickness Gauss points is fixed at three and is not a command-line argument in this element.
* A uniform drilling rotation carries no membrane strain with the GQ12 interpolation, so restrain `UR3` where it is not otherwise constrained.
* For a thin-plate formulation without transverse shear use [SGCMS](SGCMS.md), and for a triangular mesh use [DKTS3](DKTS3.md).
