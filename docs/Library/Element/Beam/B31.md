# B31

3D Displacement Based Bernoulli Beam

* Number of Nodes: 2
* Number of DoFs: 6 (Translation, Translation, Translation, Rotation, Rotation, Rotation)
* DoF Label: U1, U2, U3, UR1, UR2, UR3

## Background

[`B31`](B31.md) is the three-dimensional counterpart of [`B21`](B21.md) and shares the displacement-based Euler–Bernoulli formulation developed in the [Beam Element Overview](Beam.md).
The attached `B3DL` or `B3DC` [orientation](Orientation.md) maps the twelve global nodal DoFs to the six local deformations $\mathbf d=\begin{bmatrix}u&\theta_{zi}&\theta_{zj}&\theta_{yi}&\theta_{yj}&\theta_{xj}-\theta_{xi}\end{bmatrix}$.
At natural coordinate $\xi$ the section strain vector is

$$
\mathbf\varepsilon(\xi)=\frac{1}{L}\mathbf B(\xi)\mathbf d,\qquad
\mathbf B(\xi)=\begin{bmatrix}
1&0&0&0&0&0\\
0&3\xi-1&3\xi+1&0&0&0\\
0&0&0&3\xi-1&3\xi+1&0
\end{bmatrix}.
$$

The three rows correspond to the axial strain and to the curvatures about the local strong ($z$) and weak ($y$) axes, and each curvature is linear in $\xi$.
Only the first three section resultants, namely the axial force $P$ and the bending moments $M_z$ and $M_y$, are taken from the section, because the implementation uses only the leading $3\times3$ block of the section stiffness.
The torsional deformation $\theta_{xj}-\theta_{xi}$ is not passed to the section and is instead resisted by an elastic penalty stiffness equal to $10^3$ times the largest entry of the assembled local stiffness, which makes torsion effectively rigid.

!!! info "deviation from theory"
    Standard Bernoulli beam theory integrates the torsional moment from the section, whereas this element assigns the torsional deformation an elastic penalty of $10^3$ times the largest assembled local-stiffness entry, so the torsional response is effectively rigid and carries no physical St. Venant or warping stiffness.

This is an important modelling limitation, so use [`B31OS`](B31OS.md) when St. Venant torsion, warping or torsional plasticity is relevant.
The tangent and resistance are integrated with a Lobatto rule in the same way as [`B21`](B21.md), and the corotational option requires a `B3DC` orientation whose nonlinear-geometry flag matches the element switch.

## Syntax

```text title="B31"
element B31 (1) (2) (3) (4) (5) [6] [7]
# (1) int, unique element tag
# (2) int, node i
# (3) int, node j
# (4) int, section tag
# (5) int, orientation tag
# [6] int, number of integration points, default: 6
# [7] bool string, nonlinear geometry switch, default: false
```

## Remarks

1. The Lobatto integration is used by default.
   The number of integration points ranges from 3 to 20.
2. Please check [`orientation`](Orientation.md) for its definition.
3. To use the corotational formulation for nonlinearity, please attach a corotational formulation enabled `orientation`.
4. During initialisation the element rejects an orientation whose type is not `B3D` or whose nonlinear-geometry flag disagrees with argument `[7]`.
5. The constructor caps the number of integration points at 20.
6. The force-based [`F31`](F31.md) is preferable when inelastic bending must be captured with few integration points.
