# F21

2D Force Based Bernoulli Beam

* Number of Nodes: 2
* Number of DoFs: 3 (Translation, Translation, Rotation)
* DoF Label: U1, U2, UR3

## Theory

`F21` is a two-node, two-dimensional Euler-Bernoulli beam based on the force-based (flexibility) formulation of Spacone, Ciampi and Filippou.
It is the canonical page of the force-based beam family; see [F21H](F21H.md) for lumped end hinges and [F31](F31.md) for the three-dimensional counterpart.
Unlike a displacement-based beam, a force-based element assumes a statically admissible force field and satisfies equilibrium exactly, so plasticity can spread along the member with very few elements.

### Basic deformations and section forces

The element transformation removes the three rigid-body modes from the six global degrees of freedom and leaves three basic deformations $$\mathbf d_e=[d_1,d_2,d_3]^\mathrm T$$, namely the axial elongation and the two end rotations relative to the chord.
The conjugate basic forces are $$\mathbf q=[N,M_i,M_j]^\mathrm T$$, with $$N$$ the axial force and $$M_i$$, $$M_j$$ the end moments.
For the natural coordinate $$\xi\in[-1,1]$$ the section forces are interpolated from $$\mathbf q$$ by
$$
\mathbf s(\xi)=\begin{bmatrix}N(\xi)\\ M(\xi)\end{bmatrix}=\mathbf b(\xi)\mathbf q,\qquad
\mathbf b(\xi)=\begin{bmatrix}1&0&0\\[1mm]0&\dfrac{1-\xi}{2}&\dfrac{1+\xi}{2}\end{bmatrix}.
$$
The same matrix maps the basic deformations to the section deformations, so that integration point $$\xi_i$$ receives the two-entry vector $$\mathbf b(\xi_i)\mathbf d_e$$.
The interpolation gives a constant axial force and a moment that varies linearly between the two end values, which is the exact equilibrium solution in the absence of distributed loads.

### Element flexibility and tangent

At a section the tangent $$\mathbf k_s$$ relates section deformations to section forces, and the section flexibility is $$\mathbf f_s=\mathbf k_s^{-1}$$.
The element flexibility matrix is obtained by integrating the section flexibility over the member,
$$
\mathbf F=\int_0^L\mathbf b^\mathrm T(\xi)\mathbf f_s(\xi)\mathbf b(\xi)\,\mathrm dx\approx\sum_{i=1}^{n}\omega_i L\,\mathbf b_i^\mathrm T\mathbf f_{s,i}\mathbf b_i,
$$
where $$L$$ is the element length, $$\omega_i$$ is the integration weight, $$n$$ is the number of integration points, and $$\mathbf b_i=\mathbf b(\xi_i)$$.
The local element tangent is $$\mathbf k_e=\mathbf F^{-1}$$ and the global tangent is $$\mathbf K=\mathbf T^\mathrm T\mathbf F^{-1}\mathbf T$$, where $$\mathbf T$$ is the rigid-body-removal transformation.
In `update_status()` the trial basic deformation is compared with the deformation predicted by the current force field, the section states are updated once from the target section forces, and the basic forces are corrected by the unbalanced deformation before $$\mathbf F$$ and $$\mathbf K$$ are rebuilt.

!!! note "developer note"
    The classical force-based beam iterates at the section level until the section deformations are consistent with the element force field.
    suanPan performs a single predictor-corrector pass per `update_status()` call, which is the non-iterative algorithm recorded in the changelog for `F21`, `F21H` and `F31`.

For a linear elastic prismatic member the integrand is quadratic in $$\xi$$, so the minimum three-point Lobatto rule already evaluates the flexibility integral exactly.

### Numerical integration and large displacement

Lobatto quadrature is used by default with a configurable number of integration points between three and twenty.
It places integration points at both ends where plastic hinges usually form.
Every section copy receives a characteristic length $$\omega_i L$$ so that materials with fracture-energy regularisation use the correct tributary length.
Turning on the nonlinear geometry switch selects the corotational transformation `B2DC`, which removes rigid-body motion with the updated chord and assembles the geometric stiffness from the current element forces.
With linear geometry the `B2DL` transformation is used and no geometric stiffness is assembled.

## Syntax

```text title="F21"
element F21 (1) (2) (3) (4) [5] [6]
# (1) int, unique element tag
# (2) int, node i
# (3) int, node j
# (4) int, section tag
# [5] int, number of integration points, default: 6
# [6] bool string, nonlinear geometry switch, default: false
```

## Remarks

1. The Lobatto integration is used by default.
   The number of integration points ranges from 3 to 20.
2. To use the corotational formulation for nonlinearity, please turn on the switch.
3. Unlike 3D beam elements, there is no need to attach an `orientation` to 2D beam elements.
4. The attached section must provide a two-component deformation vector and a $$2\times2$$ tangent; fibre sections such as [`Rectangle2D`](../../Section/Section2D/Rectangle2D.md) are typical choices.
5. The parser clamps the number of integration points to at most 20 and uses 6 by default.
6. The corotational switch must not be confused with section nonlinearity: the latter is handled entirely by the section, while the former adds `B2DC` and the geometric stiffness.
7. Softening sections need regularisation through the characteristic length $$\omega_i L$$ to avoid mesh-dependent results, and the force-based interpolation cannot by itself regularise strain localisation.

## Output Type

This model supports the following additional history variables to be recorded.

| variable label | physical meaning          |
|----------------|---------------------------|
| BEAME          | local element deformation |
| BEAMS          | local element resistance  |

For example,

```text
hdf5recorder (1) Element BEAME (2...)
```
