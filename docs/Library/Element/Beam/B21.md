# B21

2D Displacement Based Bernoulli Beam

* Number of Nodes: 2
* Number of DoFs: 3 (Translation, Translation, Rotation)
* DoF Label: U1, U2, UR3

## Background

[`B21`](B21.md) is the two-node displacement-based Euler–Bernoulli beam element described in the [Beam Element Overview](Beam.md), where the general beam kinematics, quadrature and corotational transformation are developed.
The element transforms the six global nodal DoFs into three local deformations $\mathbf d=\begin{bmatrix}u&\Theta_1&\Theta_2\end{bmatrix}$, where $u$ is the axial elongation and $\Theta_1$, $\Theta_2$ are the end rotations relative to the deformed chord.
At a natural coordinate $\xi\in[-1,1]$ the section strains are

$$
\mathbf\varepsilon(\xi)=\frac{1}{L}\mathbf B(\xi)\mathbf d,\qquad
\mathbf B(\xi)=\begin{bmatrix}
1&0&0\\
0&3\xi-1&3\xi+1
\end{bmatrix},
$$

so that the axial strain $\varepsilon=u/L$ is constant and the curvature varies linearly along the element.
Here $L$ is the element length taken from the initial chord at initialisation, which is also used to normalise the section deformation as described in the [overview](Beam.md).

!!! warning "implementation limitation"
    Even with the corotational switch enabled, the element divides the local deformations by this fixed initial length rather than by the current chord length.

The section returns the axial force $N$ and bending moment $M$ conjugate to these two strain measures.
The local tangent stiffness and resistance are assembled by Lobatto quadrature,

$$
\mathbf K_l=\sum_i \frac{w_i}{L}\mathbf B_i^\mathrm T\mathbf D_{s,i}\mathbf B_i,\qquad
\mathbf f_l=\sum_i w_i\mathbf B_i^\mathrm T\mathbf s_i,
$$

where $w_i$ is one half of the Lobatto weight, $\mathbf D_{s,i}$ is the section tangent and $\mathbf s_i$ is the section resistance at point $i$.
The characteristic length assigned to each section copy is $w_iL$, which makes strain-based damage or plasticity laws mesh-objective.
Because the curvature is only linear, several elements per member are needed when the bending moment changes rapidly or when plastic hinges form, so the force-based [`F21`](F21.md) is often more efficient.

## Syntax

```text title="B21"
element B21 (1) (2) (3) (4) [5] [6]
# (1) int, unique element tag
# (2) int, node i
# (3) int, node j
# (4) int, section tag
# [5] int, number of integration points, default: 6
# [6] bool string, nonlinear geometry switch, default: false
```

## Remarks

1. The Lobatto integration is used by default.
   The number of integration points ranges from 3 to 20.
2. To use the corotational formulation for nonlinearity, please turn on the switch.
3. Unlike 3D beam elements, there is no need to attach an `orientation` to 2D beam elements.
4. The two-dimensional transformation is chosen internally as `B2DL` for linear geometry and `B2DC` when the nonlinear geometry switch is on.
5. The section supplies only the axial force and bending moment, and it must be defined as a two-dimensional section.
6. See [`EB21`](EB21.md) for an elastic element with a closed-form stiffness, [`B21E`](B21E.md) for an end-moment release and [`B21H`](B21H.md) for lumped end hinges.
