# B21H

2D Displacement Based Bernoulli Beam With Lumped End Hinges

* Number of Nodes: 2
* Number of DoFs: 3 (Translation, Translation, Rotation)
* DoF Label: U1, U2, UR3

## Background

[`B21H`](B21H.md) is a lumped-plasticity version of [`B21`](B21.md) in which nonlinear material response is confined to two finite-length end hinges and the middle of the member remains elastic.
Argument `(5)` is the normalised hinge length $$L_h=L_{\mathrm{hinge}}/L$$, capped at $$0.5$$, so that the elastic core has normalised length $$1-2L_h$$.
The elastic core is integrated with two Gauss points and its contribution to the tangent is precomputed once from the initial section stiffness, while each hinge is integrated with two points placed at $$\xi=-1$$ and $$\xi=-1+\tfrac{4}{3}L_h$$ together with the mirrored positions near $$\xi=1$$.
Only the four hinge sections contribute their updated material state to the tangent and resistance, which makes this element much cheaper than a distributed-plasticity element.

!!! note "developer note"
    The two elastic-core section copies have their trial state refreshed but their stress and tangent are never used, since the core contribution is the fixed initial-stiffness matrix and is never committed.

Since the displacement field is still the cubic Hermite interpolation of [`B21`](B21.md), the plastic rotation a hinge can accumulate is bounded by the interpolated end rotation, as noted in the remarks below.

## Syntax

```text title="B21H"
element B21H (1) (2) (3) (4) [5] [6]
# (1) int, unique element tag
# (2) int, node i
# (3) int, node j
# (4) int, section tag
# [5] double, normalized length of each end hinge, default: 0.2
# [6] bool string, nonlinear geometry switch, default: false
```

## Remarks

1. The interior is assumed to be elastic so the response can be precomputed.
   For each end hinge, two integration points are used.
2. To use the corotational formulation for nonlinearity, please turn on the switch `[6]`.
3. This element may not be that useful since the plastic rotation of end hinges are constrained by the displacement
   interpolation function, which is a cubic polynomial.
4. Unlike 3D beam elements, there is no need to attach an `orientation` to 2D beam elements.
5. The section must be capable of nonlinear response at the four hinge points, while the elastic core only needs a valid initial stiffness from the same section prototype.
6. For an ideal moment release with no hinge length use [`B21E`](B21E.md), and for distributed plasticity use [`B21`](B21.md) or [`F21`](F21.md).
