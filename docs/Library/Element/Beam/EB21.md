# EB21

2D Elastic Bernoulli Beam

* Number of Nodes: 2
* Number of DoFs: 3 (Translation, Translation, Rotation)
* DoF Label: U1, U2, UR3

## Background

[`EB21`](EB21.md) is the closed-form elastic limit of [`B21`](B21.md) and uses neither a section nor integration points.
With the initial material stiffness $E$ taken from the assigned material, the local stiffness matrix for the deformation vector $\mathbf d=\begin{bmatrix}u&\Theta_1&\Theta_2\end{bmatrix}$ is

$$
\mathbf K_l=\begin{bmatrix}
EA/L&0&0\\
0&4EI/L&2EI/L\\
0&2EI/L&4EI/L
\end{bmatrix},
$$

where $A$ is the area and $I$ the moment of inertia given in arguments `(4)` and `(5)`.
This is the standard slope–deflection relation for a prismatic member whose chord rotations have been removed by the two-dimensional transformation.
Only the initial stiffness of the material is read, and the material is never asked to update its trial state, so any hardening or nonlinear material model is ignored.
The mass matrix, when a density is supplied, is built from the product $\rho A$ and is kept constant.

## Syntax

```text title="EB21"
element EB21 (1) (2) (3) (4) (5) (6) [7]
# (1) int, unique element tag
# (2) int, node i
# (3) int, node j
# (4) double, area
# (5) double, moment inertia
# (6) int, material tag
# [7] bool string, nonlinear geometry switch, default: false
```

## Remarks

1. No matter what material model is used, only the initial stiffness is used for computation since `EB21` is an elastic beam element.
2. Unlike 3D beam elements, there is no need to attach an `orientation` to 2D beam elements.
3. The local deformation and resistance can be recorded with the `BEAME` and `BEAMS` output types.
4. Use [`B21`](B21.md) when a section-based nonlinear response is required, and [`EB31OS`](EB31OS.md) for an elastic three-dimensional member with warping.
