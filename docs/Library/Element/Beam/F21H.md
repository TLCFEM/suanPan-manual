# F21H

2D Force Based Bernoulli Beam With Lumped End Hinges

* Number of Nodes: 2
* Number of DoFs: 3 (Translation, Translation, Rotation)
* DoF Label: U1, U2, UR3

## Background

`F21H` is a lumped-plasticity variant of the force-based beam [F21](F21.md).
It keeps the exact equilibrium interpolation of the basic forces described on the canonical page, but it confines nonlinear section response to two short end regions while the interior of the member remains elastic.

The element flexibility is assembled as $\mathbf F=\mathbf F_\mathrm{elastic}+\mathbf F_\mathrm{hinge,i}+\mathbf F_\mathrm{hinge,j}$, with each contribution given by $\sum\omega L\,\mathbf b^\mathrm T\mathbf f_s\mathbf b$.
The elastic contribution is formed once from the initial section flexibility and is reused during the analysis, so that only the two hinge sections need to be updated in `update_status()`.

!!! info "deviation from theory"
    The hinge sections are updated in a single predictor-corrector pass rather than by the classical nested iteration of force-based elements.
    Both hinges are clones of the same section prototype, so the two ends share identical properties but keep independent histories.

Each hinge is integrated with two points, one at the element end and one inner Radau point, while the elastic interior uses Gauss points plus the two inner Radau points.
The parameter `[5]` is the normalised hinge length and is clamped to at most $0.5$ in the element constructor.

!!! warning "implementation limitation"
    `initialize()` computes the elastic-region size as $1-8h$ from the supplied hinge length $h$, so values above $0.125$ give a negative elastic region and negative interior Gauss weights.
    The documented parser default of $0.2$ lies above this bound.

The corotational switch has the same meaning as in [F21](F21.md): it selects the `B2DC` transformation and the geometric stiffness.

## Syntax

```text title="F21H"
element F21H (1) (2) (3) (4) [5] [6]
# (1) int, unique element tag
# (2) int, node i
# (3) int, node j
# (4) int, section tag
# [5] double, normalized length of each end hinge, default: 0.2
# [6] bool string, nonlinear geometry switch, default: false
```

## Remarks

1. The interior is assumed to be elastic so the response can be precomputed.
   For each end hinge, two integration points are used.
2. To use the corotational formulation for nonlinearity, please turn on the switch.
3. Unlike 3D beam elements, there is no need to attach an `orientation` to 2D beam elements.
4. Since the interior stays elastic, this element cannot develop a plastic hinge at midspan, and [F21](F21.md) should be used when yielding inside the member is expected.
5. The same section definition is cloned for the elastic interior and for both hinges, so all end hinges share the same section properties.
6. This formulation is the force-based analogue of a Giberson-type concentrated-plasticity model and is most economical when one element is used per member.

## Output Type

This model supports the following additional history variables to be recorded.

| variable label | physical meaning          |
|----------------|---------------------------|
| BEAME          | local element deformation |
| BEAMS          | local element resistance  |

For example,

```text
hdf5recorder (1) Element BEAME (2...)
hdf5recorder (1) Element BEAMS (2...)
# (1) int, unique recorder tag
# (2...) int, tags of elements to record
```
