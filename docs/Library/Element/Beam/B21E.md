# B21E

2D Displacement Based Bernoulli Beam With End Moment Release

* Number of Nodes: 2
* Number of DoFs: 3 (Translation, Translation, Rotation)
* DoF Label: U1, U2, UR3

## Background

[`B21E`](B21E.md) extends [`B21`](B21.md) by releasing the bending moment at one end of the member.
The release is enforced by adding an unknown end rotation to the released local rotational DoF and solving the local equilibrium equation $M_r=0$ with a Newton iteration at every global iteration.
Once the released moment vanishes, that DoF is removed by static condensation, $\mathbf K_c=\mathbf K_{bb}-\mathbf K_{ba}\mathbf K_{aa}^{-1}\mathbf K_{ab}$, where $a$ is the released rotational index and $b$ collects the remaining local deformation indices.
The condensed tangent and resistance are then transformed to the global system by the same two-dimensional transformation as [`B21`](B21.md).
Element `B21EL` releases the rotation at node `(2)` and `B21EH` releases the rotation at node `(3)`, so the released node must still possess an in-plane rotational DoF in the surrounding structure to avoid a mechanism.

## Syntax

```text title="B21E"
element B21EL (1) (2) (3) (4) [5] [6]
element B21EH (1) (2) (3) (4) [5] [6]
# (1) int, unique element tag
# (2) int, node i
# (3) int, node j
# (4) int, section tag
# [5] int, number of integration points, default: 6
# [6] bool string, nonlinear geometry switch, default: false
```

## Remarks

1. The Lobatto integration is used by default.
   The number of integration points ranges from 3 to 20.
2. To use the corotational formulation for nonlinearity, please turn on the switch.
3. To release end moment at node `(2)`, use element `B21EL` in which `L` stands for low.
4. To release end moment at node `(3)`, use element `B21EH` in which `H` stands for high.
5. Analysts shall ensure that the node with the released moment is connected to other elements that have in-plane rotational DoF.
6. Local iterations are performed to achieve a tolerance of `1E-13`.
7. Since additional rotation is involved to achieve a pinned connection, visualisation is not available.
8. Unlike 3D beam elements, there is no need to attach an `orientation` to 2D beam elements.
9. The current implementation uses a tolerance of `1E-14` and at most 20 local iterations, which is slightly tighter than the value quoted above.
10. For a hinge with a finite plastic length instead of an ideal release, use [`B21H`](B21H.md), and for a fully section-based beam use [`B21`](B21.md).

!!! note "developer note"
    The original manual quotes a local-iteration tolerance of `1E-13`, but `B21E.h` actually sets the tolerance to `1E-14` with at most 20 iterations, so the released moment is driven closer to zero than the quoted value suggests.
