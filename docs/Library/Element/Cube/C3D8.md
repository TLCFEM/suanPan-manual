# C3D8

Linear Cube/Brick

* Number of Nodes: 8
* Number of DoFs: 3 (All Translation)
* DoF Label: U1, U2, U3
* Supports Body Force
* Constant Consistent Mass Matrix With Same Order Integration

## Theory

`C3D8` is the eight-node first-order isoparametric hexahedron, also known as the Q1 brick.
Its parent domain is the cube $(\xi,\eta,\zeta)\in[-1,1]^3$ and the corner nodes follow the conventional order $(-, -, -)$, $(+, -, -)$, $(+, +, -)$, $(-, +, -)$, $(-, -, +)$, $(+, -, +)$, $(+, +, +)$, $(-, +, +)$.

The trilinear shape functions are
$$
N_I(\xi,\eta,\zeta)=\frac18(1+\xi_I\xi)(1+\eta_I\eta)(1+\zeta_I\zeta),\qquad I=1,\dots,8,
$$
where $(\xi_I,\eta_I,\zeta_I)$ are the parent-domain coordinates of node $I$.

The isoparametric maps are $\boldsymbol x=\sum_I N_I\boldsymbol x_I$ and $\boldsymbol u=\sum_I N_I\boldsymbol u_I$.
The Jacobian of the mapping is $\boldsymbol J=\partial\boldsymbol x/\partial\boldsymbol\xi=\sum_I\boldsymbol x_I\otimes\nabla_{\boldsymbol\xi}N_I$, and the physical gradients follow from $\nabla_{\boldsymbol x}N_I=\boldsymbol J^{-T}\nabla_{\boldsymbol\xi}N_I$.
A positive $\det\boldsymbol J$ must be maintained at every sampling point.

In the small-strain setting the engineering strain vector $\boldsymbol\varepsilon=(\varepsilon_{11},\varepsilon_{22},\varepsilon_{33},2\varepsilon_{12},2\varepsilon_{23},2\varepsilon_{13})$ is obtained from $\boldsymbol\varepsilon=\boldsymbol B\boldsymbol u_e$.
The implementation assembles $\boldsymbol B$ column by column as
$$
B_{1,\,3I-2}=B_{4,\,3I-1}=B_{6,\,3I}=\frac{\partial N_I}{\partial x},\quad
B_{4,\,3I-2}=B_{2,\,3I-1}=B_{5,\,3I}=\frac{\partial N_I}{\partial y},\quad
B_{5,\,3I-2}=B_{4,\,3I-1}=B_{3,\,3I}=\frac{\partial N_I}{\partial z}.
$$

The element stiffness, consistent mass and body-force vector are
$$
\boldsymbol K_e=\sum_g w_g\det\boldsymbol J_g\,\boldsymbol B_g^{\mathrm T}\boldsymbol D\boldsymbol B_g,\quad
\boldsymbol M_e=\sum_g w_g\det\boldsymbol J_g\,\rho\,\boldsymbol N_g^{\mathrm T}\boldsymbol N_g,\quad
\boldsymbol f_e^{b}=\sum_g w_g\det\boldsymbol J_g\,\boldsymbol N_g^{\mathrm T}\boldsymbol b,
$$
where $\boldsymbol D$ is the tangent of the associated 3D material, $\rho$ is the density and $\boldsymbol b$ is the body force per unit volume.
The mass matrix is subsequently made constant and is replicated over the three translational DoFs of each node.

With the nonlinear-geometry switch enabled the formulation is total Lagrangian.
The deformation gradient is $\boldsymbol F=\boldsymbol I+\sum_I\boldsymbol u_I\otimes\nabla_{\boldsymbol x}N_I$, the Green-Lagrange strain $\boldsymbol E=\frac12(\boldsymbol F^{\mathrm T}\boldsymbol F-\boldsymbol I)$ is passed to the material, and the tangent is the sum of the material term $\boldsymbol B^{\mathrm T}\boldsymbol D\boldsymbol B$ and a geometric term built from the stress returned by the material.

Element integration is selected by `IntegrationPlan(3, order, type)`, so `I` uses the six-point Irons rule, `R` uses one-point Gauss and `G` uses $2\times2\times2$ Gauss.
The one-point rule integrates the constant part of the strain field exactly but leaves twelve zero-energy hourglass modes, four per coordinate direction.
Those modes are orthogonalised against the linear displacement field to give the vectors $\boldsymbol\gamma_i$, and the stabilisation matrix is $\frac18(\mu/\det\boldsymbol J)\sum_i\boldsymbol\gamma_i\boldsymbol\gamma_i^{\mathrm T}$ replicated on each translational DoF.
Full integration of Q1 locks in bending and near incompressibility, and this element does not provide a separate selective reduced integration switch.

## Syntax

```text title="C3D8"
element C3D8 (1) (2...9) (10) [11] [12] [13]
# (1) int, unique element tag
# (2...9) int, eight corner nodes with conventional order
# (10) int, material tag
# [11] string, integration scheme, default: "I"
# [12] bool string, nonlinear geometry switch, default: false
# [13] double, hourglassing penalty multiplier, default: 1.0
```

## Remarks

1. Three integration schemes are available, they are:

    1. "I" uses Irons six-point scheme.
    2. "R" uses reduced integration with Gauss scheme, that is one point at the center of the element.
       Hourglassing control is automatically enabled.
    3. "G" uses full integration (2nd order) with Gauss scheme.

2. The nonlinearity is implemented by using total Lagrangian (TL) formulation, turn on the switch to use it.

For the hourglassing control, see [10.1016/0045-7825(84)90067-7](https://doi.org/10.1016/0045-7825(84)90067-7).
The hourglassing penalty multiplier (denoted as $$\mu$$) is an overall multiplier that is applied to the hourglassing stiffness matrix.

$$
\mu\mathbf{\gamma}_i\mathbf{\gamma}_i^\mathrm{T}.
$$

In the above, $$\mathbf{\gamma}_i$$ is identical to Eq. (47) in the reference paper.
Thus, $$\mu$$ shall be set to some value proportional to the elastic modulus.

The integration-scheme argument is case-insensitive in the parser and defaults to `"I"` when omitted.
The nonlinear-geometry switch is a boolean string and defaults to `false`.
The penalty multiplier is stored as its absolute value, so a negative input has the same effect as a positive one.
A value of zero removes the hourglass resistance, which is acceptable with full integration but permits zero-energy modes with `"R"`.
The stabilisation contributes to both the stiffness and the residual, so a nonzero penalty produces the artificial force $\frac18(\mu/\det\boldsymbol J)\sum_i\boldsymbol\gamma_i\boldsymbol\gamma_i^\mathrm{T}\boldsymbol u_e$.
Material records are sampled at the integration points and are extrapolated to the eight nodes for VTK output.
For bending-dominated or nearly incompressible problems consider [C3D8I](C3D8I.md) or the quadratic [C3D20](C3D20.md) instead of the fully integrated Q1 brick.
For the phase-field fracture and nonlocal-damage extensions see [DC3D8](DC3D8.md) and the `NonlocalC3D8` variant described below.

## Variants

`C3D8R` forces the one-point reduced-integration scheme with hourglassing control, so the integration-scheme argument is dropped: `element C3D8R (1) (2...9) (10) [11] [12]` reads only the nonlinear-geometry switch and the hourglassing penalty multiplier.
`DC3D8M` is the phase-field fracture cube that solves displacement and damage monolithically; `element DC3D8M (1) (2...9) (10) (11) (12)` takes the material tag, characteristic length and energy release rate, and adds a DAMAGE DoF at every node.
`NonlocalC3D8` is the nonlocal-damage cube; `element NonlocalC3D8 (1) (2...9) (10)` takes only the material tag, which must define exactly one nonlocal variable, and adds an NL1 DoF at every node.
