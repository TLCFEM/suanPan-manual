# T2D2

2D Linear Truss

* Number of Nodes: 2
* Number of DoFs: 2 (Translation, Translation)
* DoF Label: U1, U2

## Theory

`T2D2` is the canonical page of the truss family; see [T3D2](T3D2.md) for the three-dimensional element and [T2D2S](T2D2S.md) for the section-based variant.
A truss element is a two-node bar that transmits only axial force, so its response is derived from a single uniaxial material law.

### Geometry and strain

Let the initial nodal coordinates be $(x_1,y_1)$ and $(x_2,y_2)$, and define $L_0=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$ and the direction cosines $c=(x_2-x_1)/L_0$, $s=(y_2-y_1)/L_0$.
With the nodal displacement vector $\mathbf v=[\Delta x_1,\Delta y_1,\Delta x_2,\Delta y_2]^\mathrm T$, the current length is $L=\sqrt{(x_2-x_1+\Delta x_2-\Delta x_1)^2+(y_2-y_1+\Delta y_2-\Delta y_1)^2}$ and the axial deformation is $u=L-L_0$.
For linear geometry $u=\mathbf n^\mathrm T\mathbf v$ with $\mathbf n=[-c,-s,c,s]^\mathrm T$, so the engineering strain is $\varepsilon=u/L_0=\mathbf n^\mathrm T\mathbf v/L_0$ and the derivatives of $u$ are constant.
With the corotational formulation the direction cosines are updated from the current chord and
$$
\frac{\partial u}{\partial\mathbf v}=\mathbf n,\qquad
\frac{\partial^2u}{\partial\mathbf v^2}=\frac{1}{L}\begin{bmatrix}
s^2&-cs&-s^2&cs\\
-cs&c^2&cs&-c^2\\
-s^2&cs&s^2&-cs\\
cs&-c^2&-cs&c^2
\end{bmatrix}.
$$

### Resistance and stiffness

The strain energy of the bar is $U=\int A(u)\sigma(u)\,\mathrm du$, where $A$ is the current area and $\sigma$ is the uniaxial stress returned by the material.
The global resistance and tangent follow by differentiation,
$$
\mathbf f=\frac{\mathrm dU}{\mathrm d\mathbf v}=A\sigma\,\frac{\partial u}{\partial\mathbf v},\qquad
\mathbf K=\frac{\mathrm d\mathbf f}{\mathrm d\mathbf v}
=\left(\frac{\mathrm dA}{\mathrm du}\sigma+A\frac{\mathrm d\sigma}{\mathrm du}\right)\mathbf n\mathbf n^\mathrm T
+A\sigma\frac{\partial^2u}{\partial\mathbf v^\mathrm T\partial\mathbf v}.
$$
For linear geometry with constant area and engineering strain, $\mathrm d\sigma/\mathrm du=E/L_0$ and the familiar axial stiffness $k=EA/L_0$ is recovered.
The tangent reduces to $\mathbf K=k\,\mathbf n\mathbf n^\mathrm T$.
When the constant-volume switch is active the area is updated as $A=A_0L_0/L$, so $\mathrm dA/\mathrm du=-A_0L_0/L^2$.
With the logarithmic strain $\varepsilon_l=\ln(L/L_0)=\ln(1+u/L_0)$ one has $\mathrm d\varepsilon_l/\mathrm du=1/L$, and the tangent becomes
$$
\mathbf K=\underbrace{\frac{A_0L_0}{L^2}\big(E-\sigma\big)\mathbf n\mathbf n^\mathrm T}_{\mathbf K_l}
+\underbrace{\frac{A_0L_0}{L}\,\sigma\,\frac{\partial^2u}{\partial\mathbf v^\mathrm T\partial\mathbf v}}_{\mathbf K_g},
$$
where $\mathbf K_g$ is the geometric stiffness and becomes negative in compression.
In the implementation the nonlinear geometry switch selects the corotational transformation `T2DC`, which also assembles $\mathbf K_g$ from the current axial force.

## Syntax

```text title="T2D2"
element T2D2 (1) (2) (3) (4) (5) [6] [7] [8] [9]
# (1) int, unique element tag
# (2) int, node i
# (3) int, node j
# (4) int, material tag
# (5) double, cross sectional area
# [6] bool string, nonlinear geometry switch, default: false
# [7] bool string, whether to update sectional area, default: false
# [8] bool string, whether to use log strain, default: false
# [9] double, flexural rigidity, positive to activate Euler buckling limit, default: -1.0
```

## Remarks

1. The corotational formulation is implemented, turn on the nonlinear geometry switch to use it.
2. According to different implementation details, either a constant area or a constant volume assumption is adopted.
   If the volume is constant, the cross-sectional area would be updated based on $$A=\dfrac{A_0L_0}{L}$$.
3. The computation of strain can be altered from engineering strain (by default) to log strain.
4. By turning on all three switches, full nonlinearity can be achieved.
5. The axial force and the material stress are positive in tension and negative in compression, which is the sign convention used by the Euler buckling check below.
6. The area switch implements a constant-volume assumption corresponding to Poisson's ratio $0.5$, while the default keeps the area fixed at $A_0$.
7. With the log strain option the material strain is $\varepsilon_l=\ln(L/L_0)$ instead of the engineering strain $\varepsilon=u/L_0$, which is preferable at large stretches.
8. The attached material must be a uniaxial `Material1D` model, and the element initial stiffness is $A_0E_0/L_0$.
9. The Euler buckling check of the next section is only available for [T2D2](T2D2.md); [T3D2](T3D2.md) has no rigidity argument.

## Example

A nonlinear bar of initial length $4$ with logarithmic strain, updated area and corotational kinematics is defined by

```text
node 1 0 0
node 2 4 0
material MPF 1 100 300 .4
element T2D2 1 1 2 1 100 1 1 1
```

## Euler Buckling Limit

[added in version 2.8]

The parameter `[9]` allows one to define a positive flexural rigidity $$EI$$ that will be used to compute the Euler buckling load.
When `[9]` is negative, the check is disabled.

The truss element matches a pinned-pinned condition, for which the Euler buckling load is given by

$$
P_{cr}=\dfrac{\pi^2EI}{L^2}
$$

where $$L$$ is the length of the truss element.

For a given positive $$EI$$, $$P_{cr}$$ can be computed using only $$L$$, regardless of the used material model.
The computed axial resistance will be compared to $$P_{cr}$$ and an error will be issued if the axial resistance (in compression) exceeds $$P_{cr}$$.

!!! warning "implementation limitation"
    The critical load is evaluated once at initialisation from the initial element length and is not updated when corotational kinematics change the member length.
    Exceeding the limit issues an error instead of representing the post-buckling response.

!!! note "developer note"
    Exceeding the limit also returns a failure flag.

This is a theoretical upper bound, the design value requires an additional reduction.
