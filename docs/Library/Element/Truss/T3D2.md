# T3D2

3D Linear Truss

* Number of Nodes: 2
* Number of DoFs: 3 (Translation, Translation, Translation)
* DoF Label: U1, U2, U3

## Background

`T3D2` is the three-dimensional member of the truss family and follows the derivation given on the canonical [T2D2](T2D2.md) page.
The element connects two nodes in space and carries only the axial force computed from one uniaxial material law.

With initial length $L_0$ and unit direction vector $\mathbf e=[c_x,c_y,c_z]^\mathrm T$ along the chord, the axial deformation is $u=L-L_0$.
Under linear geometry the engineering strain is $\varepsilon=u/L_0=\mathbf n^\mathrm T\mathbf v/L_0$ with $\mathbf n=[-c_x,-c_y,-c_z,c_x,c_y,c_z]^\mathrm T$.
In the corotational formulation $\mathbf e$ is updated from the current chord and the second derivative of the deformation is
$$
\frac{\partial^2u}{\partial\mathbf v^\mathrm T\partial\mathbf v}=\frac{1}{L}\left(\mathbf M-\mathbf n\mathbf n^\mathrm T\right),\qquad
\mathbf M=\begin{bmatrix}\mathbf I_3&-\mathbf I_3\\-\mathbf I_3&\mathbf I_3\end{bmatrix}.
$$
The global resistance and tangent are $\mathbf f=A\sigma\,\mathbf n$ and
$$
\mathbf K=\left(\frac{\mathrm dA}{\mathrm du}\sigma+A\frac{\mathrm d\sigma}{\mathrm du}\right)\mathbf n\mathbf n^\mathrm T+A\sigma\frac{\partial^2u}{\partial\mathbf v^\mathrm T\partial\mathbf v}.
$$
The switches `[6]` to `[8]` have the same meaning as in [T2D2](T2D2.md): corotational kinematics, constant-volume area update and logarithmic strain.
Unlike [T2D2](T2D2.md), this element has no flexural rigidity argument and performs no Euler buckling check.

!!! warning "implementation limitation"
    A compressive member can pass through its Euler critical load without any warning, so buckling must be assessed separately.

## Syntax

```text title="T3D2"
element T3D2 (1) (2) (3) (4) (5) [6] [7] [8]
# (1) int, unique element tag
# (2) int, node i
# (3) int, node j
# (4) int, material tag
# (5) double, cross sectional area
# [6] bool string, nonlinear geometry switch, default: false
# [7] bool string, whether to update sectional area, default: false
# [8] bool string, whether to use log strain, default: false
```

## Remarks

1. The corotational formulation is implemented, turn on the nonlinear geometry switch to use it.
2. According to different implementation details, either a constant area or a constant volume assumption is adopted.
   If the volume is constant, the cross-sectional area would be updated based on $$A=\dfrac{A_0L_0}{L}$$.
3. The computation of strain can be altered from engineering strain (by default) to log strain.
4. By turning on all three switches, full nonlinearity can be achieved.
5. Tension is positive and compression negative, so the geometric stiffness contributed by the axial force is negative in compression.
6. The corotational transformation `T3DC` updates the three direction cosines from the displaced chord, whereas `T3DL` keeps the initial direction.
7. The final section-based variant [T3D2S](T3D2S.md) delegates the axial stiffness to a section and cannot update the area.
