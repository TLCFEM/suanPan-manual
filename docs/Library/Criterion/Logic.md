# Logic

Two criteria can be combined to emit termination signal under certain logical conditions.

## Syntax

```text title="Logic"
criterion LogicAND (1) (2) (3)
criterion LogicOR (1) (2) (3)
# (1) int, unique criterion tag
# (2) int, tag of first criterion in logical operation
# (3) int, tag of second criterion in logical operation
```
