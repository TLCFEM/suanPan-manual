# OS146

Open Section Wrapper

Wraps a 3D host material model into a 2D plane model that can be used with open sections.

## Theory

An open-section material retains only the axial and two transverse shear stress components of a three-dimensional state.

In a thin-walled open section the wall is free on its faces, so the stress components normal to the wall and the shear transmitted across the wall thickness are negligible compared with the axial stress $$\sigma_{11}$$ and the two membrane shear stresses $$\tau_{12}$$ and $$\tau_{13}$$.
The wrapper therefore retains the three-component work-conjugate pairs $$(\sigma_{11},\varepsilon_{11})$$, $$(\tau_{12},\gamma_{12})$$ and $$(\tau_{13},\gamma_{13})$$.
The indices $$1$$, $$4$$ and $$6$$ in the name refer to the one-based 3D Voigt ordering $$(\sigma_{11},\sigma_{22},\sigma_{33},\tau_{12},\tau_{23},\tau_{13})$$.

This class derives from the same `StressWrapper` as [PlaneStress](PlaneStress.md) and [Uniaxial](Uniaxial.md), with active set `F1={0,3,5}` and constrained set `F2={1,2,4}`.
The constrained stresses $$\sigma_{22}$$, $$\sigma_{33}$$ and $$\tau_{23}$$ are driven to zero by correcting the corresponding strain components with the host tangent block $$\mathbf D_{OO}$$.
The returned $$3\times3$$ stiffness is the static condensation of the host $$6\times6$$ tangent, so a consistent host tangent yields a consistent open-section tangent.
With the default maximum iteration of one the correction is applied in a single Newton update, while larger values of `[3]` repeat the evaluation until the constrained stresses are small.

!!! warning "implementation limitation"
    With the default `[3]=1` the constrained stresses $$\sigma_{22}$$, $$\sigma_{33}$$ and $$\tau_{23}$$ are generally not driven exactly to zero.

!!! note "developer note"
    The strain correction is computed from the host stress and tangent of the previous step and applied only once.
    With `[3]>1` the loop tests a tolerance relative to the first correction and performs at most `[3]-1` host updates, because the counter is increased and tested before each evaluation.

The companion [OS146S](OS146S.md) builds the same three-component response from a 1D axial host and an explicitly prescribed linear shear modulus instead of condensing a 3D host.

## Syntax

```text title="OS146"
material OS146 (1) (2) [3]
# (1) int, unique tag
# (2) int, 3D material tag
# [3] int, maximum iterations allowed per step, default: 1
```

The response of attached 3D material model will be output when recorded.

The name `OS146` suggests that the first (1) $$\sigma_{11}$$, the fourth (4) $$\tau_{12}$$ and the sixth (6) $$\tau_{13}$$ components are active.
All other components are assumed to be zero.

## Remarks

The host must be a registered 3D material, and the wrapper inherits its density.
Pair the wrapper with open-section beam elements such as `B31OS` together with open-section cell or fibre sections and an `B3DOSL` orientation; the supplied example uses this combination.
The wrapper reports a three-component stress and stiffness to the element, where the last two entries are shear resultants rather than in-plane membrane forces.
Recorded quantities are forwarded to the host, so the full 3D stress state of the wall is available even though the element only uses three components.
An inaccurate host tangent in the constrained block can make the single-update mode leave a residual transverse stress, in which case a smaller step or additional local iterations are needed.
For a closed or thick section use a full 3D material instead of this reduction.

## Example

```text
node 1 0 0 0
node 2 1 0 0

material Elastic3D 1 100 .2
material OS146 2 1

section Cell3DOS 1 10. 1. 1. 1. 2 10. 10.
section Cell3DOS 2 10. -1. 1. 1. 2 -10. -10.
section Cell3DOS 4 10. -1. 1. 1. 2 -10. 10.
section Fibre3DOS 3 1 2 4

orientation B3DOSL 1 0. 0. 1.

element B31OS 1 1 2 3 1 6
```
