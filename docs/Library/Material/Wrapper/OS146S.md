# OS146S

Open Section Wrapper

Wraps a 1D host material model into a 2D plane model that can be used with open sections.

## Theory

This reduced open-section wrapper keeps only the axial and two transverse shear stress components of a three-dimensional state.
It builds the three-component open-section response without a three-dimensional constitutive law.
The axial strain $$\varepsilon_{11}$$ is passed unchanged to a one-dimensional host, which returns the axial stress $$\sigma_{11}$$ and the axial tangent $$k=\mathrm d\sigma_{11}/\mathrm d\varepsilon_{11}$$.
The two shear responses are independent and linear elastic,

$$
\tau_{12}=G\,\gamma_{12},
\qquad
\tau_{13}=G\,\gamma_{13},
\qquad
\mathbf D^{\mathrm{OS}}=
\begin{bmatrix}
k&0&0\\
0&G&0\\
0&0&G
\end{bmatrix},
$$

where $$G$$ is the shear modulus supplied as the third argument.
The diagonal stiffness means that axial yielding or damage in the host does not degrade the shear response, which is a deliberate simplification of the reduced open-section model.
Like [OS146](OS146.md), the class reports a three-component stress to open-section beam elements while recording the host response.

!!! info "deviation from three-dimensional theory"
    A fully three-dimensional constitutive law generally couples the axial and shear responses through the off-diagonal terms of the tangent matrix.
    The `OS146S` implementation sets those coupling terms to zero and keeps the shear stiffness constant at $$G$$, so axial yielding or damage cannot soften the shear response.
    Use [OS146](OS146.md) with a three-dimensional host when that coupling matters.

## Syntax

```text title="OS146S"
material OS146S (1) (2) (3)
# (1) int, unique tag
# (2) int, 3D material tag
# (3) double, shear modulus
```

The response of attached 1D material model will be output when recorded.

The name `OS146S` suggests that the first (1) $$\sigma_{11}$$, the fourth (4) $$\tau_{12}$$ and the sixth (6) $$\tau_{13}$$ components are active.
All other components are assumed to be zero.

The shear response is always linear elastic with the shear modulus specified in the third argument.

The normal strain is sent to the 1D material model as the axial strain.

## Remarks

!!! warning "argument label in the syntax block"
    The comment for argument `(2)` in the syntax block calls it a 3D material tag, but a three-dimensional host is rejected.
    Supply a one-dimensional material model as the host.

!!! note "developer note"
    `OS146S::initialize` rejects any host whose material type is not `D1`.

Use a 1D host such as [Elastic1D](../Material1D/Elastic/Elastic1D.md) or a 1D hysteretic model, and use [OS146](OS146.md) when a full 3D host is available and transverse normal stresses must be condensed.
The shear modulus has units of stress and must be positive; it controls only the two shear entries and has no effect on axial yielding.
The wrapper inherits the density of the host and provides no strain-rate overload, so rate-dependent axial hosts should be used with care.
Use it with open-section beam elements and section definitions as shown in [OS146](OS146.md).
