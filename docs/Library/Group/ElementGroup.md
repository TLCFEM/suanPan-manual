# ElementGroup

An `ElementGroup` collects element tags under a single group tag so that loads and recorders can target many elements at once.
It is analogous to an element "set" in ABAQUS.

## Syntax

```text title="ElementGroup"
group ElementGroup (1) (2...)
# (1) int, unique group tag
# (2...) int, tags of elements to be included
```

## Remarks

1. If no element tags are listed, the group is filled with all elements in the domain when it is initialised.
2. Element tags can also be generated by [`generate`](../../Collection/Define/generate.md) instead of being enumerated.
3. An `ElementGroup` can be referenced by `groupbodyforce` and `GroupElement` recorders.

## Example

The following snippet selects all elements and applies a gravity body force, as in the slope analysis example.

```
generate elementgroup 1 1 2880

load groupbodyforce 1 0 -20 2 1

recorder 2 hdf5 GroupElement S 1
```
