This section provides references to all control commands.

## At a Glance

Commands are grouped by the stage of an analysis in which they are used.

| Stage | Purpose | Example commands |
|:------|:--------|:-----------------|
| Define | build the model: nodes, elements, materials, sections, loads, constraints, groups and recorders | [`node`](Define/node.md), [`element`](Define/element.md), [`group`](Define/group.md) |
| Configure | set up a step: analysis type, integrator, solver, converger and criteria | [`step`](Configure/step.md), [`integrator`](Configure/integrator.md), [`criterion`](Configure/criterion.md) |
| Process | run, inspect and save: analysis, querying, visualisation and object control | [`analyze`](Configure/analyze.md), [`peek`](Process/peek.md), [`save`](Process/save.md) |

These commands follow the [model structure](../Basic/GettingStarted/Structure.md), and the objects they create are catalogued in the [model library overview](../Library/Overview.md).
