# criterion

The `criterion` command constructs criteria that may be used to modify the model according to specific rules.
Please refer to the specific criterion types for syntax and details.

The summary page can be found [here](../../Library/Criterion/Criterion.md).

## Syntax

```text title="criterion"
criterion (1) (2) ...
# (1) string, criterion type
# (2) int, unique criterion tag
```
