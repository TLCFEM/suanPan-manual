# peek

The `peek` command prints predefined information.
It has no effect if global screen output is switched off.

## Syntax

```text title="peek"
peek node (1)
peek element (1)
peek material (1)
peek constraint (1)
peek recorder (1)
peek solver (1)
peek integrator (1)
peek group (1)
peek amplitude (1)
# (1) int, object tag

peek eigenvalue
```
