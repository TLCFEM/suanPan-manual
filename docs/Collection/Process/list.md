# list

The `list` command prints the tags of the objects of a given type that are stored in the current domain.

## Syntax

```text title="list"
list (1)
# (1) string, object type
```

## Remarks

The object type can be `amplitude`, `constraint`, `converger`, `criterion`, `element`, `expression`, `group`, `integrator`, `load`, `material`, `modifier`, `node`, `orientation`, `recorder`, `section`, `solver` or `step`.
