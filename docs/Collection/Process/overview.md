# overview

The `overview` command starts an interactive guided tour of suanPan.
It introduces the basic modelling workflow, such as defining nodes, elements, steps and running commands.
Type `q` at any prompt to quit the tour and return to normal interactive mode.

## Syntax

```text title="overview"
overview
```

## Remarks

The tour operates on a separate model, so it does not modify the current domain.
Each topic is printed step by step and the tour waits for the requested command.
Press Enter to continue after a topic is completed.
